# VFS491 2.0.3 engineering record

## Purpose

2.0.3 hardens the recognition-study instrumentation introduced in 2.0.2. The previous study tool queried a journal interval expanded by two seconds but did not filter individual records back to the actual `fprintd-verify` process interval. That could associate an adjacent capture event with the wrong verification attempt. The new version consumes `journalctl --output=json`, uses each entry's `__REALTIME_TIMESTAMP`, and retains only events timestamped between the start and exit of the verification command.

The driver-side TOD capture path, protocol, matcher settings, image data and recovery behavior are unchanged from 2.0.2.

## Study correlation changes

- Query a narrow outer journal interval, then apply an exact microsecond timestamp filter to each event.
- Store each event's `journal_realtime_us` value with the event, allowing later audits of the correlation.
- Reject malformed frame telemetry, non-finite floating-point values, invalid dimensions and inconsistent byte counts.
- Serialize study runs with a per-user advisory lock so two instances of this utility cannot overlap their measurement windows.
- Use no-follow, regular-file-only output and lock opens; write JSONL records with mode `0600` and an append lock.
- Keep the account name, command transcript, raw biometric pixels, templates and minutiae out of the output file.

The study remains a local diagnostic helper, not part of the production matching decision. It cannot correlate unrelated non-fprintd applications and should be run serially for each physical trial. The fprintd device claim remains the primary exclusivity mechanism for the sensor.

## Driver invariants retained

- Matcher threshold remains `40`.
- Enrollment remains one stage.
- Original Validity image flags remain `FPI_IMAGE_COLORS_INVERTED | FPI_IMAGE_V_FLIPPED`.
- No crop, rotate, mirror, resize, normalization, enhancement or raw-pixel rewrite has been added.
- Per-claim broker, poisoned-session handling, bounded recoverable-acquisition retry and explicit recovery are unchanged.

## Validation performed for this source

The eight dedicated verification-study tests cover parsing, malformed frame rejection, timestamp-boundary filtering, an end-to-end simulated verification/journal pair, private output permissions, symlink refusal and run serialization. The wider project component test suite is run individually because broker lifecycle tests are timing-sensitive when chained in one constrained container invocation.

The development environment does not contain the target libfprint/TOD development ABI or the private sysroot. Therefore this source has not been natively compiled, linked or packaged here. This is a source release candidate, not a hardware-certified production release. Build it on the HP EliteBook 8470p against its exact installed `1.94.7+tod1` core/TOD pair, then complete `docs/HARDWARE-ACCEPTANCE.md` before treating it as a stable driver release.
